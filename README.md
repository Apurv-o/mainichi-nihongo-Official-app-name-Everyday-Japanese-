# 毎日日本語 — Mainichi Nihongo

A cozy, offline-first Japanese study tracker and JLPT N5/N4 Kanji practice progressive web app (PWA).

## Features
- **Daily Dashboard**: Quick stepper counters for Words learned, Grammar pages, Kanji pages, and Study time (minutes/hours).
- **⏱️ Focus Timer & Stopwatch**: Live timer to time study sessions and log them directly to today's progress with quick `+15m`, `+30m`, `+1h` buttons.
- **🎴 JLPT N5 & N4 Kanji Practice**: 253 interactive 3D flashcards with Hiragana readings, meanings, mastery tracking, search, and full reading practice sentences.
- **Goals & Streaks**: Set daily target goals, track active streaks, total days, and longest records.
- **History & Calendar**: View monthly study logs, edit or delete past days, and inspect daily notes.
- **Progress Analytics**: Weekly breakdown, monthly summaries, and 6-month historical trends.
- **Offline-First & Local Storage**: Automatically uses IndexedDB with fallback to `localStorage` and memory storage.
- **Export / Import**: Safe JSON backup & restore functionality.
- **Light / Dark Theme & PWA**: Dynamic manifest, responsive design for desktop & mobile, standalone install support.
