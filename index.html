💾 Data Management

All data lives on this device (IndexedDB with automatic fallback storage). Use export/import to move your history between Windows and Android — no cloud, no account.

Backup file name: mainichi-nihongo-backup-YYYY-MM-DD.json. Imports are validated (structure, dates, numbers) — corrupted or foreign files are rejected safely. There is no automatic sync.
